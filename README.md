## Daftar Materi & Progres Praktikum
1. **Pengenalan & Instalasi Python** — Persiapan dasar dan instalasi Python.
2. **Variabel dan Tipe Data** — Penggunaan tipe data dasar (String, Number, Boolean, dll.).
3. **Operator pada Python** — Operator aritmatika, perbandingan, logika, dan penugasan.
4. **Kondisi If Else pada Python** — Percabangan logika `if`, `elif`, dan `else`.
5. **Perulangan pada Python** — Penggunaan perulangan `for` dan `while`.
6. **Lists dan Dictionaries** — Pengelolaan data koleksi terurut dan pasangan key-value.
7. **Function** — Pembuatan dan pemanggilan fungsi serta parameter.
8. **Class dan Object** — Dasar OOP (pembuatan class, atribut, method, dan instansiasi object).
9. **PIP dan Virtual Environments** — Manajemen paket dan isolasi environment dengan `venv` / `pip`.
10. **Konfigurasi Environment/IDE** — Pengaturan editor/IDE dan workspace pengembangan.
11. **README.md & Requirements.txt** — Dokumentasi repositori dan daftar dependensi (`pip freeze > requirements.txt`).

## Cara Menjalankan Program

1. Pastikan Python sudah terpasang di perangkat.
2. *(Opsional)* Aktifkan *virtual environment* jika digunakan:
   ```bash
   source .venv/bin/activate
   ```
   *(Di Windows PowerShell/CMD: `.venv\Scripts\activate`)*
3. Instal dependensi jika ada:
   ```bash
   pip install -r requirements.txt
   ```
4. Jalankan file Python yang diinginkan:
   ```bash
   python nama_file.py
   ```
